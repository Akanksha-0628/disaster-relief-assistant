# 🌪️ Disaster Relief Assistant

A responsive and intelligent chatbot designed to assist users during natural disasters by providing real-time help, emergency food suggestions, shelter information, and official government support links.

This project focuses on helping affected individuals with quick access to critical resources, using a simple and mobile-friendly chat interface.

---

## 🚀 Features

- ✅ Smart chatbot to handle disaster-related queries
- 🌍 Location-aware emergency suggestions
- 🛠️ Built with React and Tailwind CSS
- 🌐 Multi-language input support
- 📱 Fully responsive and mobile-friendly
- 🔒 Safe, accessible, and user-friendly UI
